# library

KiCad libraries for all Reality Labs projects.

## Licence

**CERN Open Hardware Licence Version 2 — Permissive (CERN-OHL-P v2).** See
[`LICENSE`](LICENSE).

Permissive: anyone may use these symbols, footprints and 3D models in their own
designs, commercial or otherwise, and is under no obligation to publish changes.
The one requirement is that notices are retained — in practice, a line crediting
this library in the downstream project's attribution file.

CERN-OHL-P rather than a software licence because these are hardware design
files, and software licences are written about copying source code rather than
about manufacturing physical objects. It is also what
[marbastlib](https://github.com/ebastler/marbastlib) uses, which projects
commonly depend on alongside this one, so no compatibility analysis is needed.

Note that the 3D models under `packages3d/` include bodies from vendor and
EasyEDA sources. Those carry their originators' terms; this licence covers the
library's own symbols, footprints and organisation.
